# Personal Portfolio Website

A modern, responsive one-page portfolio website for a freelance web developer. It showcases selected projects, technical skills, an about section, and a contact form with a lightweight project viewer.

## Features

- Responsive layout for desktop, tablet, and mobile
- Sticky navigation with mobile menu
- Hero section with developer stack and call-to-action buttons
- Project showcase gallery with lightbox viewer
- Skills section covering front-end, back-end, and development tools
- About section and contact form
- Accessible focus states and semantic HTML
- No build process or framework required

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts

## Run Locally

1. Download or clone this repository.
2. Open `index.html` in a browser.
3. No server or build step is required.

## Customization

Update the placeholder name, email address, about text, and project links in `index.html`. Project preview images are stored in `images/`.

## Deployment

This is a static website and can be deployed to services such as GitHub Pages, Netlify, or Vercel.
